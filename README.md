# File Analyzer

A simple Python program that reads a text file and analyzes its contents.

## Features

* Count the number of lines
* Count the number of words
* Count a specific word
* Find the longest word
* Search for a word
* Count the number of characters
* Interactive menu
* Basic input validation

## Project Structure

```text
file-analyzer/
├── main.py
├── sample.txt
└── README.md
```

## How It Works

The program reads text from `sample.txt` and uses different Python functions to analyze the file.

The menu allows the user to choose what they want to analyze.

## Python Concepts Used

* Functions
* `while` loops
* `for` loops
* `if / elif / else`
* Strings
* Lists
* `split()`
* `strip()`
* `len()`
* `return`
* File handling with `open()`

## How to Run

Make sure Python is installed, then run:

```bash
python main.py
```

Enter a menu option and follow the instructions.

## Purpose

This project was built to practice using Python file handling and combining previously learned programming concepts into a working application.
